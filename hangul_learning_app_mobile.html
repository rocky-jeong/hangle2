추천 학습 순서

  1. 받침 없음으로 시작합니다. 예: ㄱ + ㅏ = 가
  2. 자음만 바꿔 봅니다. 예: 가, 나, 다, 라, 마
  3. 모음을 바꿔 봅니다. 예: 가, 거, 고, 구, 기
  4. 쉬운 받침을 하나씩 붙입니다. 예: 간, 감, 강
